# HAMZA GP: Faster Than F1 (Official UK Driving Redemption)

## Files Included in This Repository
1. `index.html` — Complete HTML5, CSS3 & JavaScript arcade game + UK Driving Licence generator
2. `F1-removebg-preview.jpg` — Custom Hamza driver character sprite (place in the same root folder)
3. `.nojekyll` — Ensures GitHub Pages serves static assets directly

## How to Host on GitHub Pages
1. Upload `index.html`, `.nojekyll`, `README.md`, and `F1-removebg-preview.jpg` to the root of your GitHub repository.
2. Open **Settings > Pages**, select **Branch: `main`** and **Folder: `/ (root)`**, then click **Save**.
